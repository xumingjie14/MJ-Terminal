# 铭杰终端机 MJ Terminal

便携式个人终端：在公用/共享电脑上提供隔离浏览器 + 节点出口，不改动宿主机的系统网络设置。双击启动后守护进程在后台常驻，关闭桌面不影响连接；在系统内「设置 → 退出系统」才会完全停止。

## 下载（64 位 Windows）

到本仓库的 **Releases** 页面下载 `MJ-System-64bit.zip`，解压后运行 `MJ-System.exe` 即可，第一次运行会自动释放内置核心。本仓库为公开仓库，免登录直接下载。

## 应用内更新（v0.6 起）

程序自带 OTA：`设置 → 软件更新`。仓库是公开的，不需要令牌：守护进程会在启动时静默检查新版并预下载，在设置里点「重启并更新」即可完成升级（节点、数据、壁纸都不动）。设置里的令牌框只在仓库改回私有后才需要（且存了坏令牌会自动改走匿名请求，不会挡住更新）。构建时会同时发布 `update.json`（版本/大小/SHA-256）供程序校验更新包。

## 网站应用（v0.10 起）

常用网站可以「钉到桌面」：在「谷歌浏览器」页里添加（名字 + 网址），桌面右侧就会多一个图标（显示网站真实图标，取不到时回退为字母）。点开时以浏览器的应用模式打开——没有地址栏、没有标签页，像独立 App 一样干净，自动走节点（全局加速开着时）。快捷方式存在 EXE 旁的 `Data/apps.txt`，跟着文件夹走；删除过的默认项记在 `Data/apps-deleted.txt`，升级不会复活。预置：X、YouTube、铭杰工作站（流动性面板）、TradingView、ETF 资金流、Coinglass、Gmail、谷歌翻译、哔哩哔哩、GitHub、Vercel、ChatGPT、Gemini、Muse、TikTok。

## 桌面交互（v0.12 起）

桌面图标（系统应用、网站应用、文件夹）都可以自由拖动摆放（单击选中、双击打开，跟真实桌面一致），位置保存在 `Data/layout.json`，跟着文件夹走。在桌面空白处点右键有菜单：**新建文件夹**（网站图标拖到文件夹上即可归组，点开文件夹可把图标拖回桌面、重命名或解散）、**刷新**、**个性化**（跳到设置换壁纸）。

## 台前调度（v0.15 起）

「设置 → 台前调度」或菜单栏的 ▦ 开关：开启后桌面只显示当前应用，其他打开的应用以实时缩略图排在左侧，点缩略图切换；关闭当前应用会自动顶上一个。宿主 Windows 的窗口不在管辖范围（应用只管自己桌面内的窗口）。

## 自动构建

源码推送到 `main` 后，GitHub Actions 自动完成构建并更新 Release 中的 `MJ-System-64bit.zip` 与 `update.json`：

- Go 构建单文件 EXE（内嵌桌面页面与 sing-box 核心）
- sing-box 使用官方 1.14.4 版 `windows-amd64-legacy-windows-7` 构建，构建时自动从 SagerNet 官方 Release 下载并校验嵌入
